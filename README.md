# Le Grimoire de Jaja

Site vitrine statique en HTML, CSS et JavaScript, conçu pour être publié gratuitement sur GitHub Pages.

## Fichiers
- `index.html` : contenu et structure des pages/sections.
- `styles.css` : identité visuelle sombre, responsive, style dark fantasy.
- `script.js` : menu mobile, année automatique et emplacement de configuration du lien de soutien.

## Aperçu local
Ouvrez `index.html` dans un navigateur. La police Cinzel/Crimson Text est chargée depuis Google Fonts ; sans connexion, des polices de remplacement seront utilisées.

## Publication gratuite avec GitHub Pages
1. Créez un compte sur https://github.com/ si nécessaire.
2. Créez un dépôt public, par exemple `le-grimoire-de-jaja`.
3. Envoyez les trois fichiers du site (`index.html`, `styles.css`, `script.js`) à la racine du dépôt.
4. Dans le dépôt, ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`. Enregistrez.
6. Attendez la publication. GitHub affichera l'adresse du site dans cette même page.

## Avant la publication
- Remplacez les liens provisoires `#contact` par les pages réelles lorsque les contenus seront disponibles.
- Dans `script.js`, renseignez `donationUrl` avec votre lien de soutien (Ko-fi, PayPal ou autre). Le bouton renvoie actuellement à la section contact tant que ce champ est vide.
- Ajoutez vos propres illustrations et vérifiez les droits d'utilisation des images, polices et contenus.
- Le formulaire de contact n'est pas encore connecté ; aucun message n'est envoyé par le site actuel.
- Le site n'utilise pas de système de compte, de cookies analytiques ni de base de données.
